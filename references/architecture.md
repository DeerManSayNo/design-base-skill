# 设计资产架构参考

## 套组与项目边界

项目子系统是项目资产，内部模块是执行指令。安装时核对实际发现路径与版本，避免同名版本歧义；仅注册根入口。

## 资产归属

| 资产 | 维护内容 |
| --- | --- |
| 设计说明 | 产品基调、使用原则、页面模式，引用主题与组件入口 |
| Token 与主题配置 | 基础值、语义及组件映射、主题模式、生成与消费入口 |
| 子系统契约 | 各领域的用途、Token 引用、变体、状态、行为与验收条件 |
| 组件源码 | 共享视觉、交互和公开 API |
| 运行示例 | 关键状态、变体及代表性用法 |
| 项目入口 | 上述资产路径、检索与启动方式 |

结构与迁移以 [项目模板](../templates/README.md) 为准，保留项目现有权威来源及运行方式。

业务与工作台引用同一份组件和主题。组件通过公开接口接入数据、状态及动作，业务层处理接口调用和业务编排，示例使用模拟适配。运行时代码和开发展示入口按各自职责组织。

生成资产由源文件生成，避免双向手工维护。具体工具按项目现状选择，不强制新建独立工具链。

共享影响检查与同步执行 compose，验证执行 verify；涉及外部消费者时沿用项目版本与兼容约定。
